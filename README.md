# Customer Behavior Analysis | End-to-End Data Analytics Project

## 📌 Overview

This project focuses on analyzing customer behavior to identify purchasing patterns, understand customer preferences, and generate actionable business insights.

The project follows an end-to-end data analytics workflow, starting with data loading and cleaning in Python, followed by Exploratory Data Analysis (EDA), SQL analysis using PostgreSQL, and interactive dashboard development in Power BI. A final analytical report and presentation were created to communicate the key findings.

## 🎯 Project Objectives

- Understand customer purchasing behavior and trends.
- Clean and prepare raw data for accurate analysis.
- Perform EDA to identify patterns, relationships, and trends.
- Use PostgreSQL to answer business questions through SQL queries.
- Build an interactive Power BI dashboard.
- Present insights and recommendations through a report and presentation.

## ⚙️ How to Run

### Prerequisites

Install or set up the following tools:

- Python 3.x
- Jupyter Notebook
- PostgreSQL and pgAdmin
- Power BI Desktop

### Step 1: Clone the Repository

```bash
git clone https://github.com/gorearati119-jpg/Customer_Shopping_Trends_Analysis
```

### Step 2: Install Python Libraries

```bash
pip install pandas numpy matplotlib seaborn sqlalchemy psycopg2-binary jupyter
```

### Step 3: Load and Analyze the Dataset

- Open Jupyter Notebook.
- Navigate to the `notebooks` folder.
- Open `customer_behaviour_analysis.ipynb`.
- Update the dataset path if required.
- Run the notebook cells in sequence.

### Step 4: Run SQL Queries

- Open PostgreSQL using pgAdmin or your preferred SQL client.
- Create or select the required database.
- Load the cleaned dataset into the appropriate table.
- Open `sql/analysis_queries.sql`.
- Execute the queries to reproduce the SQL analysis.

### Step 5: Open the Power BI Dashboard

- Open the `.pbix` file from the `dashboard` folder.
- Update the data source connection if necessary.
- Refresh the data to view the dashboard.

### Step 6: Review the Report and Presentation

Open the files in the `report` and `presentation` folders to review the documented findings and final presentation.
